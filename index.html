Build tools before larger applications

Week 3 introduces project structure, dependencies, and repeatable builds. Maven is the main tool for the Java examples; Gradle and npm provide comparisons, with Yarn introduced as an alternative. Later lessons reuse the build setup for testing in week 7 and continuous integration in week 8.

  • Maven — Java project layout, POM configuration, dependencies, lifecycle phases, and JAR packaging.
  • Gradle — tasks, plugins, build scripts, and the Gradle Wrapper.
  • npm — Node.js package management, project scripts, and lockfiles; scripts invoke the configured build tools.
  • Yarn — an alternative JavaScript package manager, covered briefly.

Follow the software lifecycle

Understand and design

Describe user needs, plan small increments, and give software clear responsibilities.

Build and verify

Write understandable Java code, test its behaviour, and improve it safely.

Deliver and maintain

Create reproducible environments, automate releases, and diagnose running systems.
