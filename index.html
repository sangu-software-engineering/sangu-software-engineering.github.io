Before you begin

  • Know the basics: variables, control flow, functions, and collections, plus B1 English for technical reading. {% include week.html key="foundations" cap=true %} refreshes the programming basics.
  • Set up Java: install a JDK, version 21 or newer, and check that javac --version works.{% if setup_lesson.url %} Setup help{% endif %}
  • Plan ahead: later weeks add Git, Maven, and Docker. The About page lists what to install, and when; check early that Docker runs on your computer.
  • Find the labs: lab instructions and assignments are in the SANGU LMS. The course contents below list lecture topics.
