# SANGU Software Engineering course website

A Jekyll website for SANGU's software engineering course. The site follows the layout and navigation of the TSU Design Patterns course website, with SANGU content and branding.

The home page lists every week from `_data/weeks.yml`, and a week links to its chapter once the chapter is ready. The About page holds the learning outcomes, course format, tools to install, and resources. To write or change lessons, see [AUTHORING.md](AUTHORING.md).

## Run locally

Use Ruby 3.3 with Bundler:

```shell
bundle install
bundle exec jekyll serve
```

Open [localhost:4000](http://localhost:4000). Restart the server after changing `_config.yml`.

For a production build:

```shell
bundle exec jekyll build
```

Ruby and Bundler only build this website; they are separate from the Java tools taught in the course.

## Structure

- `_data/weeks.yml` is the course agenda and the only place week numbers are set: one entry per week with its `number`, stable `key`, `part`, title, summary, and `example`, the running example's step for that week.
- `_data/parts.yml` lists the course's parts, which group the weeks on the home page.
- `index.html` renders the home page: the "Before you begin" checklist and the course contents grouped by part, with lesson availability.
- `about.md` is the About page, at `/about/`.
- `week-01.md` is the first chapter, at `/lessons/week-01/`.
- `_layouts/lesson.html` supplies the chapter header, desktop/mobile contents navigation, and previous/next links. `_layouts/page.html` is the plain article layout used by the About page.
- `_includes/lesson-toc.html` builds a chapter's "On this page" menu from its `##` headings.
- `_includes/week.html` renders a linked week reference from a week's key.
- `examples/week-01/` contains the downloadable Java source and each program's expected output, both included directly in the chapter.
- `scripts/check-examples.sh` compiles and runs the examples and compares their output with the `.expected.txt` files.
- `.github/workflows/pages.yml` checks the examples, builds the site, and deploys it to GitHub Pages.

## Styling and diagrams

The site reuses the reference site's Tailwind CSS, Font Awesome, and Mermaid approach. Tailwind and Font Awesome load from a CDN; Mermaid loads only when a page contains a Mermaid code block. An internet connection is needed for these resources. Code highlighting is generated by Jekyll's Rouge highlighter.

## Publish

The Pages workflow runs on pushes to `main`, pull requests, and manual dispatch. Every run checks the Java examples and builds the site; only pushes to `main` and manual runs deploy, and only when both succeed. In repository **Settings → Pages → Build and deployment**, select **GitHub Actions** as the source before deploying. A successful deployment publishes the site at [sangu-software-engineering.github.io](https://sangu-software-engineering.github.io).

The favicon retains the Font Awesome attribution embedded in its SVG. Course content and Java examples are specific to SANGU; the layout was adapted from the instructor's TSU Design Patterns website.
