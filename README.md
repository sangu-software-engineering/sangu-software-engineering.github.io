# SANGU Software Engineering course website

A Jekyll website for SANGU's 13-week software engineering course. The site follows the layout and navigation of the TSU Design Patterns course website, with SANGU content and branding.

The home page presents the complete lecture agenda. Week 1 is available as a full chapter with Java examples, a programming walkthrough, expected output, and self-check questions. Weeks 2–13 remain labelled as planned and have no lesson links until their chapters are ready.

## Run locally

Use Ruby 3.3 with Bundler:

```shell
bundle install
bundle exec jekyll serve
```

Open [localhost:4000](http://localhost:4000). Restart the server after changing `_config.yml`.

For a production build:

```shell
bundle exec jekyll build
```

## Structure

- `_data/weeks.yml` contains the 13-week agenda, aligned with the course syllabus.
- `index.html` renders the course contents and lesson availability.
- `week-01.md` is the first chapter, at `/lessons/week-01/`.
- `_layouts/lesson.html` supplies the chapter header, desktop/mobile contents navigation, and next-week summary.
- `examples/week-01/` contains the downloadable Java source included directly in the chapter.
- `.github/workflows/pages.yml` builds and deploys to GitHub Pages.

The agenda contains lecture topics only. Laboratory assignments and assessment details are maintained separately.

## Styling and diagrams

The site reuses the reference site's Tailwind CSS, Font Awesome, and Mermaid approach. Tailwind and Font Awesome load from a CDN; Mermaid loads only when a page contains a Mermaid code block. An internet connection is needed for these resources. Code highlighting is generated by Jekyll's Rouge highlighter.

Mermaid support is ready for later chapters. Week 1 requires no diagram syntax, Git knowledge, object-oriented design, or testing framework. Git begins in week 2, build tools in week 3, UML and Mermaid in week 4, and automated testing in week 7.

## Build tools in the curriculum

Week 3 introduces Maven as the main Java build tool, compares Gradle and npm, and mentions Yarn as an alternative. Later Java lessons reuse Maven for testing in week 7 and CI in week 8. Maintenance and integrated review share week 13. Week 1 examples remain standalone Java files. These curriculum tools are separate from this Jekyll website's Ruby and Bundler setup.

## Check the Java examples

Use JDK 21 or newer, without preview features or external libraries. In `examples/week-01`:

```shell
javac HelloCourse.java RoomCapacityDemo.java
java HelloCourse
java RoomCapacityDemo
```

Expected output is shown in the chapter. Generated `.class` files are ignored by Git. The lesson includes the source files with `include_relative`, keeping the displayed code and downloadable examples identical.

## Add a chapter

1. Create `week-02.md` using the first chapter as a structural example.
2. Set its front matter: `layout`, `title`, `description`, `permalink`, `week`, `category_label`, `reading_time`, and `sections`.
3. Make each section ID match an explicit heading anchor, such as `{: #learning-goals }`.
4. Place runnable examples in `examples/week-02/` and include them inside Liquid `highlight java` blocks.
5. Add `url: /lessons/week-02/` to the corresponding entry in `_data/weeks.yml` only when the chapter is ready.
6. Build and check the home page, chapter navigation, downloads, and example output.

## Publish

The Pages workflow runs on pushes to `main` and manual dispatch. In repository **Settings → Pages → Build and deployment**, select **GitHub Actions** as the source before deploying. A successful deployment publishes the site at [sangu-software-engineering.github.io](https://sangu-software-engineering.github.io).

The favicon retains the Font Awesome attribution embedded in its SVG. Course content and Java examples are specific to SANGU; the layout was adapted from the instructor's TSU Design Patterns website.
